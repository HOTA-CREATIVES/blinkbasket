# Admin Panel & Management Guide - BlinkBasket

This guide outlines standard operational procedures for managers and store administrators using the BlinkBasket Operations Console.

---

## 1. Accessing the Console
*   **Gate Lock:** The Admin Console is protected by local biometrics. You will be prompted to verify via fingerprint or face ID to unlock the dashboard screen.

---

## 2. Product Inventory Management
To add a new item to the hyperlocal store catalog:
1.  Tap the **Add Product (+)** icon in the top app bar.
2.  Fill in the required fields:
    *   **Name:** Explicit catalog name (e.g. Organic Tomatoes).
    *   **Category:** Select appropriate tags (Fruits, Dairy, etc.).
    *   **Price:** Catalogue price in INR (₹).
    *   **Unit:** Size metric (e.g. 500g, 1kg).
    *   **Stock:** Current physical count available in store.
3.  Tap **ADD PRODUCT**. The item appears instantly in customer catalog views.

---

## 3. Order Rider Allocation
1.  Navigate to the **Active Orders** tab.
2.  Incoming customer checkouts appear as `PENDING`.
3.  Tap **ASSIGN DELIVERY BOY**.
4.  Select an active delivery boy whitelisted in the region.
5.  Confirm allocation. The status transitions to `assigned`, pushing the task directly to the rider's queue.
